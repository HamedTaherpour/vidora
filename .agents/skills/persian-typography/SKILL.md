# Vidora Persian typography

Use the official VibeFarsiUI guide installed at
`docs/persian-typography.md` for type scale, line height, Persian shaping,
wrapping, bidi behavior, and numeric rendering.

Apply it together with the repository's typography and accessibility contracts;
do not introduce arbitrary font or spacing values.
