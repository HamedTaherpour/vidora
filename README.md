# Application foundation

Minimal Next.js App Router foundation for local development.

## Prerequisites

- Node.js 20.9 or later
- [pnpm](https://pnpm.io) 10

## Setup

```bash
pnpm install
```

## Local development

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
pnpm format:check
pnpm lint
pnpm typecheck
pnpm test
```

## Production build

```bash
pnpm build
```
