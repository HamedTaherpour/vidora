# Vidora UI Route Inventory

This inventory records page routes and their reconciled implementation status
as of the 2026-11-24 roadmap audit. API route handlers are intentionally
excluded. A completed presentation status does not imply production backend
integration.

| Route                                            | Page / purpose                | Classification              | Dynamic parameters  | Authentication                                    | Important behavior to restore                                                  | UI status   |
| ------------------------------------------------ | ----------------------------- | --------------------------- | ------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------ | ----------- |
| `/`                                              | Home and catalog entry point  | Public                      | None                | None                                              | Catalog discovery, search entry, categories                                    | DONE        |
| `/search`                                        | Footage search and filters    | Public                      | None                | None                                              | Search, filtering, sorting, pagination                                         | DONE        |
| `/footage`                                       | Legacy footage catalog URL    | Public                      | None                | None                                              | Preserve URL; catalog behavior is rebuilt through the search surface           | DONE        |
| `/footage/[slug]`                                | Footage detail                | Public                      | `slug`              | None                                              | Published footage lookup, preview, metadata, buy-now entry                     | DONE        |
| `/purchase/[slug]`                               | Single-footage purchase flow  | Public/Auth during checkout | `slug`              | Customer auth required before purchase completion | Fixture-backed buy-now presentation; payment/order/entitlement remain deferred | DONE        |
| `/blog`                                          | Blog listing                  | Public                      | None                | None                                              | Published blog listing and SEO metadata                                        | DONE        |
| `/blog/[slug]`                                   | Blog article                  | Public                      | `slug`              | None                                              | Article lookup and SEO metadata                                                | DONE        |
| `/login`                                         | Customer OTP login            | Public                      | None                | None                                              | Phone normalization, OTP request/verification, customer session                | DONE        |
| `/login/continue`                                | Customer session continuation | Public/session-aware        | None                | Customer session resolution                       | Continue authenticated flow                                                    | DONE        |
| `/session`                                       | Legacy customer session entry | Public/session-aware        | None                | Customer session resolution                       | Preserve safe continuation redirect                                            | DONE        |
| `/session/continue`                              | Legacy continuation alias     | Public/session-aware        | None                | Customer session resolution                       | Preserve continuation redirect                                                 | DONE        |
| `/dashboard`                                     | Customer dashboard            | Auth                        | None                | Customer session required server-side             | Account summary, library/order/profile navigation                              | IMPLEMENTED |
| `/dashboard/library`                             | Customer purchase library     | Auth                        | None                | Customer session required server-side             | Development-preview library cards; real entitlements/downloads remain deferred | IMPLEMENTED |
| `/dashboard/library/[purchaseReference]`         | Purchased footage detail      | Auth                        | `purchaseReference` | Customer session required server-side             | Ownership check, protected downloads                                           | IMPLEMENTED |
| `/dashboard/library/[purchaseReference]/invoice` | Legacy purchase invoice       | Auth                        | `purchaseReference` | Customer session required server-side             | Retained authenticated placeholder; orders modal is canonical                  | IMPLEMENTED |
| `/dashboard/orders`                              | Customer orders and invoices  | Auth                        | None                | Customer session required server-side             | Fixture-backed order history/modal; real commerce remains deferred             | DONE        |
| `/dashboard/profile`                             | Customer profile              | Auth                        | None                | Customer session required server-side             | Read-only authenticated phone profile; account editing remains deferred        | DONE        |
| `/admin/footage`                                 | Admin footage catalog         | Admin                       | None                | Admin session required server-side                | Footage management, publication, support operations                            | UI_RESET    |
| `/admin/footage/[id]/edit`                       | Admin footage editor          | Admin                       | `id`                | Admin session required server-side                | Metadata, cover, preview, originals, publication mutations                     | UI_RESET    |

Routes marked `DONE` or `IMPLEMENTED` may still be fixture-backed presentation
surfaces. Planned capabilities and production backend behavior are labeled in
the behavior column rather than being inferred from route existence.
